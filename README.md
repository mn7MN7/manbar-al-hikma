# 🌟 منبر الحكمة (Manbar Al-Hikma)
موسوعة تفاعلية لدرر وحِكم الإمام علي بن أبي طالب (عليه السلام)، تم تصميمها وبرمجتها بأسلوب عصري يدمج الأصالة التقنية والتصميم الفاخر.

## ✨ الميزات الرئيسية
* **تصفح ذكي وفوري:** استعراض المقولات وتصنيفها تلقائياً (العلم، الصبر، العقل، الزهد، العدل، الأخلاق).
* **بحث فوري متقدم:** بحث ذكي مع فلترة سريعة تتجاوز التشكيل والحركات العربية.
* **مولد صور فاخر (AI-Style):** تصميم وتنزيل بطاقات مقولات ملكية عالية الدقة (1200x630) مع إطارات ذهبية وزخارف إسلامية وتوهج ناعم.
* **نظام المفضلة (LocalStorage):** إمكانية حفظ الحِكم المفضلة في متصفحك للرجوع إليها في أي وقت.
* **نسخ سريع ونظيف:** زر نسخ فوري للمقولات بضغطة زر واحدة مع إشعارات تفاعلية.

## 🛠️ التقنيات المستخدمة
* **Backend:** Python, Flask
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS), Google Fonts (Amiri & Cairo)
* **Storage:** Local text-file processing (`imamali` & `imamali-2`) & Browser LocalStorage
